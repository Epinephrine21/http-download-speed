# Замер скорости HTTP скачивания

Консольный скрипт делает 10 последовательных GET-запросов к одному URL. Каждый ответ читается до конца, затем начинается следующий запрос. Нужен Python 3.10 или новее. Устанавливать пакеты не нужно.

## Запуск

```shell
python download_speed.py "https://example.com/path/to/test-file.bin"
```

Подставьте прямую ссылку на файл на своём сервере или на ресурс, который разрешает такие замеры. Для воспроизводимого результата возьмите один и тот же файл и не запускайте одновременно другие скачивания. Можно изменить тайм-аут сетевой операции, например `--timeout 60`.

Для проверки без интернета запустите в отдельном терминале `python -m http.server 8000 --bind 127.0.0.1` из папки с тестовым файлом. Затем передайте скрипту `http://127.0.0.1:8000/test-file.bin`.

## Что выводит скрипт

- Время каждого запроса и размер тела ответа в байтах. Таймер работает от начала запроса до полного чтения тела, включая ожидание начала ответа и перенаправления, если они есть.
- Среднее время в секундах и общий объём в байтах.
- Скорость в Мбит/с (Mbit/s). Один мегабит равен 1 000 000 бит. Формула — `8 × общий объём в байтах ÷ суммарное время в секундах ÷ 1 000 000`. Поэтому итог учитывает и короткие, и длинные ответы пропорционально времени.

Скрипт читает тело блоками и не хранит файл в памяти. В объём входят только байты тела HTTP-ответа. Результат зависит от сервера, маршрута и размера файла. При ошибке HTTP, тайм-ауте или неполном ответе скрипт сообщает номер замера, завершает работу с кодом 1 и не печатает итог за десять запросов.
